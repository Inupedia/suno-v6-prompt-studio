# 试听后修正与局部编辑

用户只有文字描述时，按其反馈提出假设，不声称已经听到音频。每轮集中处理一个主要问题，给更新后的所需字段，尽量保留有效部分。用户只让改副歌，就不顺手重写整首。

| 症状 | 先检查 | 保守修正 |
| --- | --- | --- |
| 曲风漂移 | 流派相互争主导、词太多 | 保留一个主流派及关键配器，删同义词与跨风格杂项 |
| 中文糊、双语卡顿 | 字密度、语言切换、混响与转音 | 缩句，按句切换语言，减少转音；Style 强调清楚贴前的人声 |
| 副歌像第二段主歌 | hook 不明确、主副歌密度一致 | 重写短核心句并实际重复；减少主歌配器，让副歌打开 |
| 人声太远 | huge reverb、distant、washed-out 等 | 改成 close/upfront lead；Exclude 选 heavy vocal reverb、distant lead vocals |
| 国风像普通流行 | 只写 Chinese style，没有声音角色 | 明确一件民族主奏及演奏方式，按需要加旋律色彩 |
| 尾奏又冲起来 | 全曲无范围的 epic build 指令 | 明确 chorus-only lift、quiet resolving outro，不清空有效 Style |
| 器乐冒出人声 | vocal chops/choir 等残留 | 清除这些正向词，Style 明确 instrumental，Exclude 有针对性补充 |
| 标签被唱出来 | 标签长、说明像散文 | 缩短或移至 Style，保留常用段落标记 |

“局部修改”是要粘贴到编辑功能的指令，不能假装仅靠换 Lyrics 就一定保持原音频。用户要编辑指令时可在三栏之外单独给；只要一句改词指令时直接给该指令：

```text
仅将第二遍副歌的“把灯留到天亮”替换为“把梦留到天亮”。保留其他歌词、原有旋律轮廓、节奏长度、人声与编曲。若无法自然容纳新词，仅调整这一句的音符时值。
```

用户没给原音频或旋律时，承诺的范围只到文字层面。需要精确编辑位置时请求段落或时间点，不编造时间戳。不要保证 100% 局部保留。
